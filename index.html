Security architecture

Every layer below is implemented in the app itself. There is no server component, because there is no way to reach one.

Encryption & hardening

🔐 AES-256-GCM at rest

Authenticated encryption with keys held in the Android keystore, never written to app storage.

📁 Credential-encrypted sandbox

App files live in a CE-protected sandbox with 0600 permissions.

🧠 Memory zeroization

Decrypted plaintext buffers and passphrases are overwritten with zeros in RAM immediately after use.

🗑️ Multi-pass shredding

Deleted files are overwritten with pseudo-random data before unlinking, so they are not recoverable from flash.

⏱️ Brute-force lockout

A mandatory 24-hour lockout after 3 consecutive failed PIN attempts.

👆 Biometric unlock

Optional fingerprint unlock alongside your PIN.

🚫 Screen privacy

Optional FLAG_SECURE blocks screenshots and app-switcher previews.

Coercion defense

🎭 Decoy vault

A second, independent PIN opens a completely separate empty vault. The real vault's database handle, paths, and decrypted buffers are dropped on every lock, so a decoy session cannot reach real media even in memory.

🔀 Keypad scrambling

The PIN keypad randomizes its digit layout on every entry, defeating shoulder surfing and smudge attacks.

🧷 Independent lockout

Unlocking with the decoy PIN does not reset the real vault's brute-force counter, so it cannot be cleared by switching PINs.

Organized, not just hidden

A vault you can actually search. Kura uses booru-style category prefixes to tag media, with a different color per category.

🏷️ Category prefixes

c: character, a: artist, s: series, m: meta. Prefixes drive sorting and filtering but stay hidden in the UI.

🎨 Per-category colors

Each category renders in its own color, so tags stay scannable at a glance and readable in monochrome mode.

🔎 Smart search

Searching miku also matches c:miku. Exclude with -tag. Multiple tags are ANDed together.

🗂️ Categories

Separate flows for photos, videos, and GIFs, each independently hideable. Favorites, sorting, and grid density are all configurable.

🎨 Themes

Dark, AMOLED, and light themes with accent colors and a monochrome mode.

📤 Portable backups

Encrypted .kura archives with tag manifests, written anywhere via the system file picker. Auto-detects legacy formats and plain ZIP.

One permission. That's the whole list.

Kura declares only USE_BIOMETRIC, used solely to unlock your vault. There is no INTERNET permission, no analytics, and no third-party SDKs. The app is architecturally incapable of phoning home — and you can check for yourself: 

aapt dump permissions kura.apk
